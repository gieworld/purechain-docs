# Production checklist

Before anyone depends on your network.

## Validator set

- [ ] **At least 4–5 signers**, on independent infrastructure. Clique halts when
      a majority is unavailable, and there is no slashing — liveness is purely
      operational.
- [ ] Signers in **different failure domains** — not one host, rack, or region.
- [ ] Real keys, generated by you. Never tutorial or development keys.

## Security

- [ ] **Validators are not publicly reachable.** Only RPC nodes are.
- [ ] Validator RPC bound to localhost or a private interface.
- [ ] Public nodes expose **`eth,net,web3` only** — never `admin`, `personal`,
      `debug`, `miner`, or `clique`.
- [ ] `--http.corsdomain` and `--http.vhosts` scoped tighter than `*`.
- [ ] Signer keys stored securely; password files not world-readable.

!!! warning "Free gas means no economic spam cost"
    Your protection is the permissioned signer set, restricted RPC access, the
    block gas limit, and per-account pool limits. **Opening RPC widely is the
    signal to consider a minimum tip** — see
    [Free gas](../01-overview/free-gas.md#if-fees-are-ever-needed).

## Configuration

- [ ] **`--txpool.pricelimit 0` on every node.** Verify by relaying a zero-fee
      transaction through each one.
- [ ] Same binary and byte-identical genesis everywhere.
- [ ] GPO flags on public RPC nodes.
- [ ] `--miner.gaslimit` set if you raised `gasLimit` in genesis.

## Operations

- [ ] **Sequential bring-up procedure documented** — never start all nodes at once.
- [ ] Monitoring on block production, peer counts, and missed sealing turns.
- [ ] Alerting that distinguishes *node down* from *node up but not sealing*.
- [ ] Datadir backups, and a **tested** restore.
- [ ] `SIGINT` with a real grace period on shutdown — a hard kill risks database
      corruption. See [Docker](docker.md).
- [ ] A restart runbook that includes the **relay check** — a restarted node
      silently stops relaying until re-armed. See
      [Operations](../03-operating/operations.md#after-every-restart).

## Before upgrading anything

- [ ] Pre-upgrade datadir backup on every node.
- [ ] Upgrade rehearsed on a throwaway network first.
- [ ] Roll one node at a time: RPC nodes first, then validators.
- [ ] **Never `debug.setHead`** — in-place rewinds can fork the chain.

!!! danger "Fork activation is a one-way door"
    Rolling back to stock geth is only possible **before** your first
    consensus-affecting fork activates. With `zeroBaseFee` set, the binding limit
    is `londonBlock`. After that, recovery means restoring a backup — not
    swapping the binary. Schedule forks comfortably in the future and keep the
    backup.

## Ecosystem

- [ ] Block explorer deployed — see [Tooling](../06-tooling/explorer.md).
- [ ] Faucet, if you want easy onboarding.
- [ ] Chain ID registered publicly if the network is public.
- [ ] Genesis file and client release published so others can join.
